## Usage

### With Web Components

```html
<ss-icon icon="sign-out"></ss-icon>
```

### With icon tag

```html
<i class="ss ss-sign-out"></i>
```

### With custom stroke width / thickness

```html
<ss-icon icon="sign-out" thickness="1.2"></ss-icon>
```

### Node.js

```javascript
const icons = require('@bookklik/senangstart-icons/icons');
const svg = icons['sign-out'];
console.log(svg);
```
